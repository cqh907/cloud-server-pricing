## 三、38 元、199 元、1025 元，差的不只是钱

低价档和常规档最大的分水岭是产品类型：**轻量应用服务器** 和 **CVM/ECS**。

轻量的共同特征：套餐式售卖，配置固定，支持升级但不支持降配；有月流量包上限，超了限速或另付费；CPU 多为共享调度；不支持 GPU/FPGA 等异构计算；网络隔离和自定义能力弱于 CVM。同配置下，常规 CVM/ECS 的价格通常是轻量的 2–3 倍。

CVM/ECS 给的是自定义 VPC、安全组、弹性公网 IP、云硬盘自由挂载、在线升降配、快照与镜像。这些功能个人博客用不上，但一旦要接数据库、做多机内网、配负载均衡，轻量的套餐边界就会挡路。

## 四、续费价才是真价格：把三年账算出来

首年价和续费价必须分开算，这是低价套餐最容易踩的坑。

腾讯云标准型 S5 的 199 元/年，官方写的是“可同价续费 1 年”。按公开的三年成本口径：首年 199 元，第二年 199 元，第三年恢复原价约 600 元，三年合计约 998 元。所以“199 元”只锁定前两年，不是永久价。

阿里云要按套餐区分，不能笼统说涨或不涨。99 元/年 2核2G 经济型 e 明确写的是新老用户同价、续费不涨价；但阿里云 2核4G 的活动价 800 多元/年，续费可能到 1400 元。同一个品牌，不同套餐的续费政策可以完全相反，下单前必须点开具体套餐的续费说明。

腾讯云蜂驰型 BF1 走的是另一条路：没有“续费同价”，但给了折扣梯度，续费 1 个月 7 折、1 年 5.5 折、3 年 3.9 折起。确定长期用，一次性续 3 年比按年续便宜约三成。

一个简单的判断方法：把首年价、第二年续费价、第三年续费价写在一张纸上加总，再和另一家比。只看首年，京东云 28 元和腾讯云 199 元差 7 倍；按三年算，差距会缩小到 3 倍左右。

## 五、200M 不一定比 5M 快

带宽数字是第二个容易误判的地方。

阿里云轻量的 200M 是峰值带宽，实际持续吞吐受流量包额度和调度策略限制，跑满 200M 的时间取决于你买了多少流量。腾讯云锐驰型的 200M 是无流量上限的峰值带宽，口径又不一样。京东云和芯飞云标注的 5M、10M 通常是独享带宽，数字小但稳定可预期。

对个人站点的实际意义：1M 带宽约 128KB/s，够纯文字博客；3M 约 384KB/s，能撑日 PV 几千的图文站；5M 配 CDN 可以覆盖大多数中小企业官网。看到“200M”就以为能扛视频流量，是最常见的误判。

## 七、常见问题

**38 元/年的云服务器能买吗？**
能买，但要清楚买到的是什么。阿里云 38 元是 2核2G 200M 峰值轻量，腾讯云 38 元是 4核4G 3M 轻量，都是秒杀价、有身份或时间限制，且都是轻量产品。拿来建个人站、做测试没问题，跑高并发生产业务会被流量包和共享 CPU 卡住。

**续费会不会涨？**
看具体套餐。阿里云 99 元/年 2核2G 续费同价；阿里云 2核4G 活动价 800 多元/年，续费可能到 1400 元；腾讯云 S5 199 元/年同价续费 1 年，第三年恢复原价；蜂驰型 BF1 续费按 7 折/5.5 折/3.9 折梯度走。没有统一规律。

**轻量应用服务器能跑生产吗？**
低流量、单机、无复杂内网的生产可以，比如企业官网、个人电商、小程序后端。需要多机内网、负载均衡、独立数据库、GPU 计算的场景不行，得换 CVM/ECS。

**200M 带宽是不是比 5M 快？**
不一定。200M 多是峰值带宽，受流量包和调度限制；5M 多是独享带宽，持续可用。选之前看清标注的是峰值还是独享，以及月流量额度。

**同配置为什么价格差几倍？**
四个变量：产品类型（轻量还是 CVM/ECS）、带宽口径（峰值还是独享）、流量是否封顶、节点地域。把这四项对齐，价差会小很多。

**三家大厂的稳定性有区别吗？**
公开的 SLA 都是 99.975%，数据可靠性都是 99.9999999%（9 个 9），都是三副本存储、T3+ 数据中心。差异在别处：腾讯云第九代 CVM 单实例网络 PPS 6750 万、超 20 线 BGP；阿里云 30+ 地域；华为云 25+ 地域。腾讯云还把基础 DDoS 防护、主机安全基础版、安全组、网络 ACL 列为免费包含，包年包月到期后进回收站而不是直接删除。
